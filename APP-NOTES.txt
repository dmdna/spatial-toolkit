IMPLEMENTED TOOLS

Smart Measure
  Trigger places chained nodes on actual collision surfaces. A live segment
  readout follows the pointer. Selecting an existing node finishes the path;
  the palette has explicit Finish Path and Close Area actions. Polygon area works
  on floor, wall and other planar outlines, including concave outlines.
  Crossing, duplicate, collinear and nonplanar outlines are rejected.
  Area requires coplanarity within 2 cm. The snap grid uses 1 cm or half an inch.
  Feet/inches round to one eighth of an inch; square feet use the area conversion.
  The app refuses placement when no mapped surface is available.

Fit Check
  Enter exact width, height and depth through the wrist keypad (cm or inches),
  or adjust using +/−. A translucent box preview sits at the pointed floor.
  A collider and kinematic Rigidbody support collision queries. Overlapping
  placement is refused; dragging previews become red when blocked. Rotate the
  held controller to yaw the furniture; snap mode uses 15-degree yaw steps.
  These are kinematic placement constraints, not a free-falling furniture sim.

Picture Hanging
  Enter equal frame width/height, gap, count (1–8), and hanger distance below
  the top. The app centers the group on the wall and draws frame outlines and
  individual nail crosshairs. The hanger inset is supplied by the user; the app
  does not infer hook locations, picture-wire sag or wall fastener suitability.

Level & Plumb
  Place a gravity-aligned grid on a wall. Point the controller along the object
  edge. The readout turns green within one degree of horizontal or vertical.
  This measures controller orientation. It does not recognize or track an
  arbitrary physical object held up against the grid.

Snapshots
  Editor capture uses Unity ScreenCapture. Android capture uses the consumer
  PICO Platform Highlight API: initialize, start session, capture, SaveMedia.
  It requires a configured PICO Platform app ID and successful platform calls.
  The palette/pointer are hidden during capture. Passthrough composition and
  Gallery/smartphone availability remain explicit device acceptance checks;
  a successful SDK SaveMedia response is not proof of either behavior.

INTERACTION AND VISUALS

The non-dominant controller or tracked hand carries the wrist palette.
Rotating its local up axis upward reveals the menu. The controller trigger
or Pin Menu action pins/unpins it. A world-space menu is available when
only one hand/controller is tracked or when using hands-free dwell.

As of 2026-10-28, native PICO hand and optional eye tracking are enabled.
Auto mode follows controllers or gaze/pinch with hand-ray fallback. Controls
also offers hand-ray-only, eye/head-pinch and hands-free eye/head dwell.
Pinch selects/places; pinch and hold an existing item to drag; release to
drop. Menu actions cover all button shortcuts, reach, rotate and delete.
Single-hand use and a head-dwell recovery menu do not require controllers.
See SETUP.txt, CONTROLLER-FREE OPERATION, for the full mapping and validation
limits. This is app input support within the existing PICO XR mode.

Dominant trigger: place / select. Grip: drag a node, furniture box or wall tool.
Throw a held item behind the head and release above the throw-speed threshold
to delete it. A/X: undo. B/Y: toggle snapping. Thumbstick up/down adjusts pointer
reach (0.2–12 m). The platform Menu button is left to PICO system behavior.
Left-handed mode swaps the controller roles. Undo keeps the last 50 actions.
Rooms are limited to 100 artifacts and measurement paths to 128 nodes.

The UI uses dark translucent rounded panels, mint/coral/lavender accents,
an exact 0.002 m controller ray and unlit overlays. Other guides modestly thicken
with distance for readability. Readout text uses an overlay shader so billboard
labels do not disappear into wall geometry. Both custom shaders include
instancing and stereo macros and are retained through scene material assets.

Desktop: left click = trigger, right drag = grip, Z = undo, B = snap,
mouse wheel = pointer reach. The palette stays visible without a controller.
Click a dimension row to open the numeric keypad.

ROOM PERSISTENCE

Save Room creates/persists a PICO spatial anchor and stores its UUID with the
geometry in room-local coordinates. A retained runtime handle continuously
updates the room pose. Lost localization hides saved overlays and blocks new
placement. Load queries and locates the saved anchor before replacing the
current workspace. Failed localization preserves existing work.

Device anchor support must be enabled before XR loader initialization. No
world-coordinate fallback is presented as a persisted real-room anchor.
Editor sessions are explicitly marked simulated and cannot load on device.
Writes stage a temporary file and retain a backup when replacing an old save.
Loaded session geometry is validated before native calls or rendering.

Save files use Application.persistentDataPath. The automated interaction suite
overrides storage into .tools/checks/workbench-session so it does not overwrite
the user's saved room. No cloud service or account is used for room geometry.

SELECTION AND INTERACTION UPDATE (feature release 0.3.0)

Active Measure paths finish on their current or immediately previous node.
Returning to an earlier node closes a valid area at that node. A suffix
closure retains the earlier segments as a separate open measurement. Invalid
outlines stay active with the validation reason. A node from another path may
supply the closing vertex when it makes a valid area.

A short pinch selects any placed item. The main panel shows Edit Selection:
Measure/Level nodes offer Finish Path or Start New Path, plus Delete. Starting
a path at a selected node preserves the original path/area. Fit and Hang load
the selected item's actual values; dimension, count, gap and inset changes
update only that item in real time. Fit resizing preserves its floor contact
and rejects overlaps. Select the tool tab or place on an empty surface to
leave selection editing. All edits and deletes remain undoable.

Hold a selected item's pinch for 0.22 seconds and move (or hold 0.4 seconds)
to drag. Controller grip still drags directly. Level paths own their gravity
grid via gridId, with compatible inference for older saves. Removing an
intermediate node reconnects the remaining line. Removing the gridded first
node removes the entire path and its grid. Moving the first node moves the
grid with it.

Floating menus can be moved with a pinch-hold or controller grip on the thin
top margin. A minimized menu can be moved through the same gesture on its
background. A short pinch still expands the pill; drag release leaves it
floating where placed. Wrist menus cannot be dragged. Brief occlusion of the
menu wrist holds the existing pose for 0.7 seconds rather than jumping.

Automatic hand input and Hands Only now aim along wrist-to-middle-knuckle
tracking, with index-knuckle/native-aim fallbacks and light temporal smoothing.
This avoids the SDK shoulder-biased aim direction and allows wrist rotation
to steer the ray, even while pinched. Explicit eye/head pinch modes retain
captured-gaze dragging. Hand presence no longer depends on the validity of
its SDK aim ray. Native pinch flags remain the selection signal.

Pointer line and dot render in queue 4100, sorting order above the canvas,
with Always depth testing. Other measurement geometry keeps its normal depth
test. Opaque high-contrast menus therefore do not cover the interaction ray.

HAND AND MENU HOTFIX (0.3.1)

Restores the pre-0.3 hand interaction: PICO system aim poses for hand rays,
Auto's optional eye/head fallback policy, and captured ray direction during
pinched dragging. Hand rotation still controls Fit box yaw, while hand
translation moves the captured ray. The ray is no longer rebuilt from the
wrist-to-knuckle axis. When valid fingertip poses are available, the visible
ray begins between thumb and index tip and ends at the actual system-pointer

ROOM AND FEEDBACK PATCH (0.3.2)

The menu faces the player in pinned, wrist, fallback and dragging states with
world-up orientation (no roll). Dragging retains its exact cursor anchor while
updating that upright orientation. Eye/head aiming and dwell show a dot only;
hand/controller pointing retains both the ray and dot.

Selections share one accent per preset across Measure/Level nodes, Fit and
Hang. Selected items change tint; hover adds an accent outline (node halos
or bounding edges). Node hit colliders are 1.5 times the visible radius,
without changing the physical node size or the snap grid. Nearby node targets
win over the level grid's background collider. Hand tracking immediately
returns to the menu's preferred hand once that hand is tracked again; held
input must be released after the input-source change.

A physical press on Load room loads on release. Holding uses the same
0.45-second grace and 1.2-second fill as Undo. The label changes to Delete
Room (Hold), with a status hint and cancellation on aim/focus/tracking loss.
Completion deletes the saved room file, backup and temp file, and unpersists
their PICO anchors. Current live measurements remain in the workspace.

The workspace coordinate frame is initialized once and is not rebased when
its geometry becomes empty. Saving an active path rebuilds its visuals.
Clear All detaches the live anchor, restores root visibility, clears transient
path/selection state even if already empty, and removes orphaned visuals.
It preserves the saved room file. This prevents a new first node from being
placed in a frame that the saved anchor moves underneath it.
